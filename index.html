Core principles

Four commitments held across active Real-Fruit-Snacks projects today, paired with the three supporting repositories behind the brand, app themes, and front door.

  1. 01 / LOCAL

    Local-first by default

    Every tool runs directly on your machine—whether a native Rust or Go binary, a Windows C# or PowerShell client, a Kali workflow, or an offline browser app.

  2. 02 / PRIVACY

    No accounts or tracking

    Zero signups, zero analytics beacons, and zero background cloud dependencies sitting between you and your own data.

  3. 03 / OPEN

    Source-first on GitHub

    Every active project ships public, inspectable source code alongside dedicated documentation pages, open issues, and pull requests.

  4. 04 / DIRECT

    Direct downloads & reproducible setups

    Install, clone, or run straight from each repository with predictable dependencies and zero vendor lock-in.
